# 置换检验 ≠ Fisher 精确检验

## 问题

`build_index.py` 和 `index.html` 中，假设检验的方法论说明将"配对置换检验"（Paired Permutation Test）误称为"Fisher 精确检验"（Fisher's Exact Test），并将第 4 问答为"是"（即：认为这个检验就是女士品茶）。

## 两个检验的关系

| | 配对置换检验（你实现的） | Fisher 精确检验（女士品茶） |
|---|---|---|
| **数据结构** | n 对配对观测值 | 2×2 列联表 |
| **检验目标** | 配对均值差是否显著偏离 0 | 两个分类变量是否独立 |
| **数学基础** | 穷举 2^n 种符号分配 | 超几何分布 |
| **p 值计算** | 极端均值排列数 ÷ 2^n | 在边际固定下算格子概率 |
| **经典例子** | 随机区组实验 | 女士品茶（Lady Tasting Tea） |

**共同点**：都是精确检验（exact test），都通过穷举所有可能情况计算 p 值，不依赖渐近分布。**但它们是不同的检验，适用完全不同的场景。**

## 代码实现

当前实现（`build_index.py` 第 294-302 行）是**完全正确的配对置换检验**：

```python
# 对每对数据计算差值 diff = classical - other
# 穷举全部 2^n 种符号分配
for signs in itertools.product([1, -1], repeat=n):
    perm_mean = sum(s * d for s, d in zip(signs, diffs)) / n
    if perm_mean <= obs_mean:  # H₁: 文言 < 其他语言
        count_extreme += 1
fisher_p = count_extreme / total
```

逻辑正确，无需改动。**只改命名和文档。**

### 3. 第 4 问建议回答

> 不是同一个检验，但精神一致——都是穷举所有可能性做精确推断，不依赖渐近分布。
> 女士品茶检验的是 2×2 列联表的独立性（基于超几何分布），这里检验的是配对数据的均值差（基于符号置换）。不同场景，不同数学基础。

## 什么时候改

改命名不影响统计结果和 p 值——只是一个文档纠错。可以在下一次修改 `build_index.py` 时顺手改掉，不需要专为此重建页面。

- 当前实现、单边选择、α 态度、四种方法取舍论证——**全部正确**。
