# text-embedding-ada-002 是什么

---

## 和 GPT-3 的 ada 基本没关系

只是共享了 "ada" 品牌名，表示"最低成本档位"。模型结构、用途、tokenizer、发布时间完全不同。

| | GPT-3 ada | text-embedding-ada-002 |
|---|---|---|
| 是什么 | 文本生成模型 | **嵌入模型**（embedding model） |
| 参数量 | 350M | 未公开 |
| 输出类型 | 续写文字 | 1536 维浮点数向量 |
| 输入格式 | 一个 prompt 字符串 | 一段文本 |
| 用途 | 写文章、翻译、分类、摘要 | 语义搜索、聚类、相似度计算、RAG |
| Tokenizer | r50k_base (50K) | cl100k_base (100K) |
| 发布时间 | 2020 年 6 月 | 2022 年 12 月 |
| 定价 | 按生成 token 收费 | 按输入 token 收费（$0.0001/1K tokens） |

---

## 命名解析

```
text-embedding- ada - 002
      │          │     │
      │          │     └─ 第 2 版（迭代编号，001 从未公开发布）
      │          └─────── Ada Lovelace → 最低价档位的品牌名
      └────────────────── 嵌入模型（区别于补全/对话模型）
```

OpenAI 的 GPT-3 时代用科学家名字划分价格档位：

```
Ada     ← 最便宜，"入门级"
Babbage ← 便宜
Curie   ← 中等
Davinci ← 最贵，"旗舰级"
```

text-embedding-ada-002 是嵌入模型中最便宜的，所以挂上 ada 的品牌。它和生成模型 ada **没有共享任何模型参数**，只是营销命名。

---

## 工作原理

```
输入文本: "OpenAI released GPT-4 in March 2023"
         ↓
   text-embedding-ada-002
         ↓
输出向量: [0.0123, -0.0456, 0.0789, ..., 0.0345]
          └──────── 1536 个浮点数 ────────┘

这个向量编码了文本的"语义位置"：
  - 语义相近的文本 → 向量在空间中距离近 → 余弦相似度高
  - 语义无关的文本 → 向量在空间中距离远 → 余弦相似度低
```

### 典型使用场景

**语义搜索**：
```
1. 把所有文档用 ada-002 向量化
2. 用户提问 → 也向量化
3. 找提问向量和文档向量余弦相似度最高的 5 篇
4. 返回给用户
```

**RAG（检索增强生成）**：
```
1. 用户提问 → ada-002 向量化
2. 从知识库检索最相关的文档片段
3. 把片段 + 用户提问一起喂给 GPT → 生成带引用的回答
```

**聚类/分类**：
```
1. 把所有客服工单向量化
2. 在向量空间里做 k-means 聚类
3. 发现 80% 的工单集中在"退款问题"和"订单查询"两类
```

## 2024 年被替代

```
2024.01  text-embedding-3-small (512维, 更小更快更便宜)
         text-embedding-3-large (3072维, 精度更高)

text-embedding-ada-002 → 仍可用但官方推荐迁移到 3 系列
```

新系列去掉了 "ada" 品牌名，改用 small/large 表示规模。编码统一到 cl100k_base，和 ada-002 相同。

### 3 系列的改进

| | ada-002 | 3-small | 3-large |
|---|---|---|---|
| 维度 | 1536 | 512-1536（可调） | 256-3072（可调） |
| 定价 | $0.0001/1K | $0.00002/1K（5 倍便宜） | $0.00013/1K |
| 支持缩短维度 | ❌ | ✅ | ✅ |
| 性能 | 基准 | 更优 | 大幅更优 |

维度可调是最大改进：如果只需要粗略的语义匹配，可以降到 256 维，向量数据库的存储和检索成本降低 10 倍以上。
